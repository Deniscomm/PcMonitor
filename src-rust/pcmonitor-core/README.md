# PC Monitor — Rust core (этап 1)

`pcmonitor-core` — первая Rust-часть PC Monitor. Ядро собирается в `rlib` и `pcmonitor-native.exe`; WPF подключается к нему как к локальному дочернему процессу через поток JSON Lines. DLL не загружается приложением.

## Реализовано

- Общие Rust-типы датчиков и устройств, русские названия/единицы, порядок групп, фильтрация `NaN`/бесконечностей и температурных порогов, форматирование.
- Реальный WMI-инвентарь: Windows/ПК, BIOS/плата, CPU, DIMM, GPU, диски, тома и сетевые интерфейсы.
- Живые WMI-показания: загрузка CPU, занятая/свободная RAM, чтение/запись накопителей.
- Сетевые счётчики через `sysinfo`: байты приёма/отдачи, накопленный объём и скорости по измеренному интервалу между снимками.
- `--watch` выдаёт один компактный JSON-объект в строке; min/max ведутся в течение жизни процесса. Ошибки идут как JSON `error`/`warnings`; отсутствующие значения не подменяются нулями.
- C# мост держит один sidecar, читает stdout асинхронно и останавливает процесс при паузе/закрытии мониторинга.

## Сборка и запуск

Из корня `D:\ии`:

```bat
scripts\build-rust-core.bat
app\pcmonitor-native.exe
app\pcmonitor-native.exe --watch --interval-ms=1000
```

Тесты:

```powershell
$env:RUSTUP_HOME='D:\ии\.work\tools\rustup'
$env:CARGO_HOME='D:\ии\.work\tools\cargo'
$env:PATH="$env:CARGO_HOME\bin;$env:PATH"
cargo test --all-targets --manifest-path .\src-rust\pcmonitor-core\Cargo.toml
```

Для сборки требуется Rust stable `x86_64-pc-windows-msvc` и Visual C++ Build Tools; подойдёт также системный Cargo.

Для WPF-сборки также требуется .NET SDK 10. Он установлен локально в `.work\tools\dotnet`; BAT-сборки подхватывают его без изменений глобальной установки. Если политика Windows запрещает неподписанный EXE, требуется разрешённая подпись или правило доверия; приложение не меняет политики безопасности.

## Что пока остаётся в C# / LibreHardwareMonitor

Это инкремент, не полный перенос драйверной части. LibreHardwareMonitor/PawnIO пока продолжает читать температуры CPU/платы/NVMe, вольтажи, обороты вентиляторов, подробные GPU датчики/SPD и управлять вентиляторами. Rust выдаёт только реально реализованные показания; неподдержанные данные не эмулируются. WPF GUI, авто-/стресс-тесты, рендеры и GPU tuning пока остаются в C#. WMI `LoadPercentage` — системная оценка Windows, не высокочастотный CPU benchmark.
