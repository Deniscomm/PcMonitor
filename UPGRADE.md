# PC Monitor — обновление Release

## Исправления рендеров

Трассировка, мех, комната с отражениями, закат и ночной город проверены настоящим D3D11 на RTX 2070: все 5 шейдеров собрались и дали непустые цветные кадры. Исправлены переворот UV, ошибочный blur комнаты и оси фасадов/окон города. Мех остаётся настоящим procedural-шеллом с волокнами; постобработка больше не размазывает отражения.

Живое превью рисуется отдельно от стресс-нагрузки при 320×180, а UI показывает измеренную скорость именно этих кадров. На машине разработки за 10 повторных кадров получено: трассировка 77,7 FPS, мех 72,0, комната 64,9, закат 72,3, город 65,0. Это скорость небольшого превью, не обещание FPS на другом GPU. Стресс-тест продолжает считать выбранный полный пресет вплоть до 4K и 32× реальных GPU Draw-проходов; точные 100% зависят от GPU, драйвера, сцены и охлаждения.

## Настройки и диагностика

- В авто-тесте доступны собственные длительности нагрузки/простоя, размер RAM и дискового файла; значения сохраняются. Для каждого диска можно выбрать тип вручную. USB-флешки запускаются только при явном включении USB-категории; пустой список дисков больше не означает «тестировать все».
- В меню датчика сохраняются ручные режимы достоверности: автоматический, достоверный, недостоверный; скрытие и игнорирование остаются независимыми настройками.
- В системной информации исправлены подписи частот памяти в единицах SMBIOS MHz и недостоверные выводы об XMP/EXPO; объём VRAM читается из 64-битного DXGI-источника.
- Минимизация в трей выключена по умолчанию и мигрирует так же для прежних настроек; закрытие в трей, автозапуск и остальные параметры по-прежнему настраиваются.
- Названия тестов и рендеров очищены от сравнения с чужими бенчмарками.

## Проверка сборки

- WPF/.NET: `Release`, 0 ошибок компиляции.
- Rust: `cargo test --all-targets` — 7/7; `cargo build --release --all-targets` завершился успешно.
- Проверка пяти GPU-сцен: D3D-компиляция и цветной кадр для каждой сцены; среднее live-превью выше указано по 10 кадрам.
- На RTX 2070 ранее был замерен стресс-тест 4K×32 длительностью 60 секунд: 99% загрузки, максимум 74,7 °C, 31 616 Draw; автоматический тепловой стоп 85 °C сохранён.
- В исходниках и комплекте приложения Python-файлов нет. Внешние скрипты Rust toolchain не являются зависимостью приложения.

## Portable и размер

Сжатый self-contained single-file Release проверен публикацией: `PcMonitor.exe` — 69,0 МБ вместо прежнего набора около 166 МБ (сокращение примерно 58%). Рядом остаются настоящий Rust sidecar, `d3dcompiler_47.dll` и, если доступен, установщик PawnIO. Для переноса нужна вся папка, не один EXE.

Сборка: `scripts\\publish-portable.bat [папка-назначения]`. Приложение и Rust sidecar собираются в Release; .NET SDK, Rust и Python на целевом компьютере не нужны.
